# Проектная работа 7. RAG-бот

## 1. Исследование моделей и инфраструктуры

### Контекст

Цель — корпоративный ассистент QuantumForge Software для поиска по внутренним регламентам, архитектуре, поддержке и onboarding-документам.

### Сравнение вариантов

| Вариант | LLM | Эмбеддинги | БД | Плюсы | Минусы | Итог |
|---|---|---|---|---|---|---|
| Локальный | Ollama/Hugging Face | Ollama `nomic-embed-text` | Qdrant | приватность, нет оплаты за токены | нужна инфраструктура и обслуживание моделей | основной для чувствительных документов |
| Облачный OpenAI | OpenAI API | OpenAI Embeddings | Qdrant | качество и простота запуска | стоимость и передача данных наружу | резервный вариант для несекретных данных |
| Облачный Yandex | YandexGPT | Yandex Embeddings | Qdrant | русскоязычный стек и managed API | зависимость от облака и тарифа | вариант для российского облака |
| Гибридный | локальная/облачная по профилю | локальные | Qdrant + BM25 | можно выбирать режим по классу данных | сложнее эксплуатация | рекомендуемый production-подход |

### Выбор

В текущем прототипе используются Qdrant, BM25 и локальные Ollama-модели. Qdrant выбран вместо FAISS, потому что проекту нужны отдельный сервис, payload-метаданные, обновление индекса и несколько клиентов. Для маленького учебного offline-примера FAISS был бы проще, но для целевого корпоративного сценария Qdrant удобнее.

Текущая production-конфигурация: Python backend, Rust CLI, Qdrant, Postgres, frontend на React/Vite, Ollama. Для учебной сдачи добавлен отдельный offline-режим FAISS: `faiss_rag.py` + `requirements.educational.txt`. Параметры текущего production-чанкинга и retrieval описаны в [architecture.md](architecture.md).

### Серверные варианты

| Профиль | CPU/RAM/GPU | Когда использовать |
|---|---|---|
| Demo | 4 vCPU / 8 GB / без GPU | небольшая база и API-модель |
| Local standard | 8 vCPU / 32 GB / NVIDIA 12–16 GB | локальная LLM 7–14B и эмбеддинги |
| Production | 16 vCPU / 64 GB / NVIDIA 24 GB | несколько пользователей и локальная генерация |
| Cloud hybrid | 8 vCPU / 32 GB / без GPU | локальный retrieval + облачная LLM |

Рекомендуется Local standard для приватных данных; Cloud hybrid — если приоритетом являются скорость запуска и стоимость эксплуатации.

## 4. RAG-бот

Реализованы загрузка документов, retrieval, объединение векторного и BM25-поиска, генерация ответа, источники и web-интерфейс. Доступны Python, Rust и Hybrid flow.

До сдачи нужно подтвердить в коде и тестах:

- few-shot: 1–2 примера из той же предметной области;
- управляемое объяснение ответа без публикации скрытого рассуждения модели;
- честный ответ при отсутствии релевантного контекста;
- 3–5 успешных диалогов и 1–2 отказа.
