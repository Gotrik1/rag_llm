# Рефакторинг: первый цикл

Цель: уменьшить связность frontend-кода и сохранить текущие API-контракты,
RAG-логику и поведение интерфейса.

## Этапы

1. Вынести общую HTTP-обвязку из `ui/src/App.tsx` в `ui/src/api.ts`.
   Контроль: `npm run build`; не меняются URL, payload и сообщения ошибок.
2. Вынести типы ответов API и модели UI в отдельный frontend-модуль.
   Контроль: TypeScript build и ручная проверка чата, загрузки и техпанели.
3. Разделить `App.tsx` на компоненты рабочего пространства, навигации и
   технической панели.
   Контроль: сохранение assistant-ui runtime и существующих API-контрактов.
4. Добавить целевые тесты для HTTP-клиента и критичных пользовательских
   сценариев: запрос, загрузка документа, проект/чат, ошибка backend.
   Контроль: CI и локальный smoke test.

Каждый этап выполняется отдельным commit и может быть откатан независимо.
