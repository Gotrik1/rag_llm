## Заключение по структуре

В проекте есть рабочие границы модулей и большой набор регрессионных проверок,
но декомпозиция не завершена. Главные места концентрации обязанностей —
`rag_agent.py`, `evidence_selection.py`, `ui/src/App.tsx` и совместимые
обработчики `web_ui.py`. Комментарии объясняют текущие контракты; они не заменяют
разделение этих модулей.

При подготовке передачи основные операции HTTP вынесены в прикладные сервисы.
Нельзя утверждать, что во всех контроллерах теперь отсутствует бизнес-логика:
старый диспетчер, настройки провайдеров и диагностические операции ещё требуют
постепенного переноса.

## Обязательные контракты при изменениях

- Пользователь и его права берутся из доверенного контекста, а не из тела
  запроса. Фильтрация источников выполняется до использования в ответе.
  `allowed_sources=None` означает старый неограниченный режим; пустой набор
  означает отсутствие разрешённых источников. UUID физической загрузки и
  редакция не должны схлопываться до отображаемого имени документа.
- Настройки модели фиксируются на запрос. Переключение модели в соседнем чате
  не должно менять уже запущенную генерацию. Диагностика не должна смешиваться
  между потоками.
- В устойчивом режиме сообщение и задание сохраняются до выполнения моделью.
  Разрыв соединения прекращает доставку, но не отменяет серверное задание.
  Без устойчивой очереди защита `asyncio.shield` не переживает смерть процесса.
- У сообщений успешный статус `complete`; у заданий — `completed`. Эти строки
  не взаимозаменяемы. При `202` клиент должен продолжать читать состояние.
- Кеш Python точный и зависит от контекста, модели, снимка корпуса и границ
  видимости. Частный контекст нельзя выдавать через общий кеш. Наличие записи
  в кеше не заменяет проверку актуальности источников и доказательства публикации.
- Поле `score` не обязательно для канонического раздела. Неизмеренный ранг
  передаётся как `null`; его нельзя выдумывать, превращать в ноль или считать
  основанием удалить документ из Debug.
- Ссылки и проверки используют исходный текст и идентичность документа.
  Проекция текста для модели не должна незаметно менять оригинал доказательства.
  OCR может ошибаться в индексах и знаках формул.
- Индексация использует один writer для общего BM25-снимка. Увеличивать
  параллельность ingestion без изменения публикации индекса нельзя.

   Зависимость не патчилась; адаптер покрыт отдельными тестами.

`C-Users-gotri-Documents-LLM` без этих функций: его свежесть не подтверждена.
Для текущего разбора использовать проверенный серверный v17; перед передачей
графа отдельным файлом восстановить и проверить его экспорт.
Один статус `indexed` или совпадающий Git HEAD недостаточны: при повторном
индексировании сервер может восстановить старый артефакт без новых файлов.
Проверять сигнатуру недавно изменённой функции, особенно при незакоммиченных
изменениях.
