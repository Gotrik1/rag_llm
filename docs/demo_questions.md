## 5 вопросов с ожидаемым ответом

1. Какие роли описаны в модели контроля доступа?
2. Какие права есть у владельца системы?
3. Какие права отсутствуют у администратора?
4. Что такое Workspace в архитектуре системы?
5. Какие системные инварианты должны соблюдаться?

Для каждого скриншота желательно оставить видимыми ответ, список источников и выбранный flow mode.

4. Как настроить Kubernetes-кластер в другой компании?
5. Как называется столица Марса в этой базе знаний?
