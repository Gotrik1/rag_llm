# Оценка покрытия базы знаний

В репозитории есть стартовый набор в `golden_questions.txt`; перед сдачей его нужно проверить и адаптировать под фактические 30+ документов.

Нужно иметь 10–15 golden questions:

- 6–8 вопросов по существующим документам;
- 3–5 вопросов по удалённым или отсутствующим сущностям.

Для каждого запроса логируются текст, timestamp, наличие чанков, длина ответа, статус и источники. Скрипт `evaluate.py` должен запускать вопросы последовательно и считать минимум количество успешных ответов, отказов и нерелевантных источников.

Запуск: `python evaluate.py`. Результат записывается в `logs/evaluation.jsonl`.

Итоговый отчёт должен ответить на три вопроса: какие темы покрыты плохо, сколько пробелов найдено и какие документы нужно добавить или переписать.
