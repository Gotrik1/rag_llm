# Записка для ревьюера

В рабочем проекте автора уже была задача, близкая к проектной работе: разработка корпоративного RAG-ассистента для поиска по архитектурной документации. Поэтому в ветку `RAG` был вынесен и доведён до учебного формата существующий прототип.

Что было сделано в рамках подготовки к сдаче:

- самостоятельно разработан веб-интерфейс на React/Vite;
- добавлены Python/Rust/Hybrid-потоки обработки;
- реализованы Qdrant, BM25, FAISS-режим, источники и метаданные чанков;
- добавлены Docker Compose, обновление индекса, golden set и автоматические проверки;
- добавлены few-shot-примеры, контролируемое обоснование ответа и защита от prompt injection.

В качестве корпуса использованы 35 рабочих архитектурных Markdown-документов из отдельной подборки. Для этой демонстрации автор не стал искусственно переписывать названия сущностей и выдумывать новый словарь терминов: документы были взяты в исходном виде, поскольку они уже содержат предметную область, недоступную базовой модели. Это является осознанным отклонением от требования об анонимизации терминов и должно учитываться при проверке.

Документы следует публиковать только при наличии разрешения на их использование. Если публикация исходных материалов недопустима, перед отправкой PR их необходимо заменить на обезличенную копию и добавить `terms_map.json`.
