# Network Topology

## Назначение

Описывает сетевые зоны, подсети, правила firewall и маршрутизацию трафика между компонентами системы.

## Сетевые зоны

```markdown
┌──────────────────────────────────────────────────────────┐
│                    INTERNET                              │
└──────────────────────────┬───────────────────────────────┘
                           │
                    ┌──────▼──────┐
                    │   Nginx     │ (reverse proxy)
                    │  :80/:443   │
                    └──────┬──────┘
                           │
┌──────────────────────────▼───────────────────────────────┐
│                  DMZ / Public Zone                       │
│  frontend :3000                                          │
└──────────────────────────┬───────────────────────────────┘
                           │
┌──────────────────────────▼───────────────────────────────┐
│                 Application Zone                         │
│  backend API :5000      NATS :4222                       │
└──────────────────────────┬───────────────────────────────┘
                           │
┌──────────────────────────▼───────────────────────────────┐
│                  Data Zone                               │
│  PostgreSQL :5432        PgBouncer :6432                 │
└──────────────────────────────────────────────────────────┘
```

## Правила Firewall (UFW)

### Входящий трафик (Inbound)

| Порт | Протокол | Источник  | Назначение                 |
| ---- | -------- | --------- | -------------------------- |
| 22   | TCP      | IP DevOps | SSH доступ                 |
| 80   | TCP      | 0.0.0.0/0 | HTTP → редирект на 443     |
| 443  | TCP      | 0.0.0.0/0 | HTTPS                      |
| 5432 | TCP      | app-zone  | PostgreSQL (только внутри) |
| 6432 | TCP      | app-zone  | PgBouncer (только внутри)  |
| 4222 | TCP      | app-zone  | NATS (только внутри)       |

### Исходящий трафик (Outbound)

| Порт | Протокол | Назначение                     |
| ---- | -------- | ------------------------------ |
| 443  | TCP      | GitLab, внешние API (WB, OZON) |
| 5432 | TCP      | PostgreSQL на соседнем сервере |
