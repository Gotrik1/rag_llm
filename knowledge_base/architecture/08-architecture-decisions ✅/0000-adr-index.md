## Примечания

1. **Номер ADR** — уникальный номер для каждого решения.
2. **Индекс** — краткая метка для идентификации, которая может отражать категорию решения, например, `RBAC`, `Unit`, `Multitenancy` и т.д.
3. **Название** — краткое описание решения.
4. **Дата** — дата создания или принятия решения.
5. **Комментарий** — текущий статус ADR: `Proposed`, `Accepted`, `Rejected`, или другие пометки.
6. **Ссылка на файл** — ссылка на сам файл ADR в репозитории проекта.
